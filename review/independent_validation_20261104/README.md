# Independent validation of the SmolVLA confirmation evidence

**No archived paper-evidence replay has been run.** This directory holds an independent recount of
the archive, a model-free replay harness tested on synthetic fixtures, and a frozen protocol
awaiting Alba's approval. It is not an independent confirmation of the paper's outcomes.

Start with `REPORT.md`, then `protocol/PROTOCOL.md` and `protocol/PROTOCOL_AMENDMENT_01.md`.

| Path | Contents |
|---|---|
| `audit/` | standard-library recount (`independent_audit.py`) and its planted-defect controls; post-hoc re-analysis (labelled) |
| `replay/` | harness, fixture recorder, bundle extractor, stage orchestrator, tests and drills |
| `fixtures/` | 20 synthetic trajectories from non-paper tasks (see `fixtures/NOTICE.md`) |
| `protocol/` | frozen protocol, amendment, Stage 1 sample manifest, environment and asset manifests |
| `test_runs/` | every recorded test run, including failed ones (see `test_runs/README.md`) |

## Reproduce

Audit (any Python ≥3.10, standard library only, from the repository root):

    A=experiments/runs/refinement_refresh_final_001
    V=review/independent_validation_20261104
    python3 -I $V/audit/independent_audit.py $A/confirmation_completed.tar.gz $A/confirmation_plan.json \
        $A/paper_analysis/primary_report.json /tmp/audit.json
    python3 -I $V/audit/test_audit_mutations.py $A/confirmation_completed.tar.gz $A/confirmation_plan.json \
        $A/paper_analysis/primary_report.json /tmp/audit_mut /tmp/audit_mut.json

Replay environment (Python 3.12.3; versions in `protocol/replay_env_freeze.txt`):

    uv venv -p 3.12.3 .venv
    uv pip install -p .venv/bin/python --no-deps hf_libero==0.1.4 robosuite==1.4.0 bddl==1.0.1
    uv pip install -p .venv/bin/python mujoco==3.8.1 numpy==2.2.6 scipy==1.18.1 numba==0.67.0 \
        llvmlite==0.49.0 Pillow opencv-python-headless==4.13.0.92 networkx==3.6.1 easydict==1.13 \
        gymnasium==1.3.0 hydra-core==1.3.6 omegaconf==2.3.1 future==1.0.0 cloudpickle==3.1.2 \
        torch==2.7.1 matplotlib pyyaml termcolor==3.3.0 h5py==3.16.0 huggingface_hub
    # hf_libero's robomimic -> egl-probe dependency does not build on macOS and is not needed for physics.
    # Assets: snapshot lerobot/libero-assets at revision 0b3ea86be5fe169d0fd036ae63d1070ec09e90f6 and
    # link it as site-packages/libero/libero/assets; the tree must match protocol/libero_assets_0b3ea86_manifest.tsv.
    # Write a config.yaml (assets, bddl_files, benchmark_root, datasets, init_states) and export
    # LIBERO_CONFIG_PATH to its directory; MUJOCO_GL=cgl on macOS, egl on Linux.

Tests (synthetic fixtures only):

    .venv/bin/python -I $V/replay/test_harness.py $V/fixtures/fixtures.jsonl /tmp/harness
    .venv/bin/python -I $V/replay/drill_protocol.py $V/fixtures/fixtures.jsonl /tmp/drill /tmp/drill.json
    .venv/bin/python -I $V/replay/test_stage_logic.py $V/fixtures/fixtures.jsonl /tmp/stage /tmp/stage.json

Fixtures (regenerated byte-identically on the test host; needs the two LIBERO demo files named in
`fixtures/NOTICE.md`):

    .venv/bin/python -I $V/replay/make_fixtures.py DEMO_DIR /tmp/fixtures.jsonl --demos-per-task 8

`replay/run_protocol.py` refuses archived bundles (exit 5) without a release that approves the
frozen protocol.
