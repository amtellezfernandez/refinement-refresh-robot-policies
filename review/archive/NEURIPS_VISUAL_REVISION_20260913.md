# NeurIPS visual revision - 2026-09-13

The discovery figure was regenerated as a two-panel vector PDF. Panel (a)
retains all 12 discovery outcomes and their original bootstrap intervals. Panel
(b) derives the minimum-denoising, shortest-feasible-prefix choices under the
separately normalized arithmetic and fixed-input host-time coordinates. The
script computes these choices from the retained calibration values; no transfer
outcome is read and no scientific value is changed.

The figure now uses a colorblind-safe blue/vermilion/green palette, distinct
markers and line styles, darker lines, direct budget labels, and an explicit
takeaway caption. PDF and PostScript font output is set to 42. The regenerated
figure contains only embedded CID TrueType DejaVu Serif fonts; the previous
Type 3 font is absent from the final paper.

The selector and frozen-prediction tables were consolidated into one table with
grouped headers and the original half-native primary row marked in bold. Appendix
tables use `booktabs`, descriptive headers, direction arrows, and captions that
state their takeaway. The discovery task table uses full task names and grouped
headers. The redundant mutation heatmap was removed; its compact numerical table
and explanatory text remain.

Validation: the discovery analysis was rerun from its complete 480-attempt
journals and reproduced the original values. The paper builds to ten pages:
six main-content pages, one reference page, and three appendix pages. The PDF is
US Letter, has no Type 3 or unembedded fonts, no overfull boxes or unresolved
references, and all ten rendered pages were visually inspected.
