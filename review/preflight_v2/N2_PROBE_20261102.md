## Limits

- CPU and OSMesa only, with no policy, server or GPU.
- Official state 0 only, and 15 steps per task. Later contact-rich steps and other states are not covered.
- Images are the client's 256 px render; no generated state was tried on this tree.
- This shows the two configurations behave identically here. It does not show either matches a reference evaluator.
- The switch is not applied: `run_preflight_v2.sh` still points at `$W/libero-config`, and the RTX bundle is old.

## Related finding: Alba's environment check

`check_openpi_client_environment.py` in PR #1 calls `Path(libero.__file__)`. With this source tree, `libero.__file__` printed `None` in the actual client interpreter (`alba-v2-probe-env2`), because the top-level `libero` is a namespace package. So the check would raise an uncaught `TypeError`. **This comes from reading the code with that printed value; her script has not been run.** It does not affect whether the import works, and needs a small fix before use.
