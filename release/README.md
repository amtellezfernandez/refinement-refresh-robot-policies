# Release artifacts

This directory contains the immutable NeurIPS workshop submission and its
supporting files.

- `submitted.pdf`: frozen submitted manuscript.
- `primary_transfer_supplement.zip`: frozen primary-transfer supplement.
- `archive/2026-09-13/`: dated source and artifact snapshot.

The continuing manuscript is `../paper/main.tex`; its generated working PDF is
`../paper/working.pdf`. New analyses belong under `../experiments/runs/` and
must not modify the dated archive.
