# Executed paired deployment pilot

These artifacts record the 2026-09-12 SmolVLA/LIBERO execution used by the
paper. The run used checkpoint revision
`6721902bc4d61e50a3bfdb11dfb4cb626f05d102` and the pinned LeRobot source tree
recorded in each runtime manifest.

- `development_gate_001/` contains the deterministic action-level checks,
  independent work counters, profiler reconciliation, image perturbations, and
  zero-action environment control.
- `development_parity_001/` contains one four-condition development block and
  the exact controlled-noise parity check against the pinned upstream evaluator.
- `paired_pilot_001/` contains the frozen 80-attempt schedule, runtime manifest,
  episode summaries, and append-only step journal for two LIBERO Spatial tasks,
  five initial states, two policy seeds, and four deployment configurations.
- `analysis_001/` contains the validated paired state-bootstrap analysis and
  information-recovery audit generated by `../execution/analyze_execution.py`.

The paired run overlapped another GPU process. Its action counts, work counters,
paired outcomes, and simulator records support the reported count-quality
analysis. Host and CUDA durations are retained as provenance but are
GPU-contended and must not be used for clean latency or efficiency claims.

The analysis is conditional on the two declared tasks. The two policy seeds are
averaged within each initial state; the bootstrap resamples the five states
within each task and gives the two tasks equal weight. These intervals are
descriptive and do not establish equivalence, non-inferiority, or transfer to a
new task.
